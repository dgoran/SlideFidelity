SlideCheck Helper lets the SlideCheck add-in for PowerPoint see exactly which fonts this Mac can use, so it can report fonts that are missing here.

It installs a small background app that starts when you sign in, and a certificate that is valid only for this computer's own address (localhost). It reads font names only and never opens your presentations.

To remove it later, run sudo "/Library/Application Support/SlideCheck/Helper/uninstall.sh" in Terminal.
