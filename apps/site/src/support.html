Install

In PowerPoint, open Home › Add-ins, search for SlideFidelity, and select Add. SlideFidelity needs PowerPoint for Mac 16.105 or later, PowerPoint for Windows (Microsoft 365, version 2601 or later), or PowerPoint for the web for every feature. Older versions show which features they cannot run.

Account and subscription

Sign in from the Account section in SlideFidelity with your email address. You receive a 6-digit code. New accounts get a 30-day Pro trial with no card needed.

To subscribe, update payment details, download invoices, or cancel, sign in on the website with the same email address.

Start or manage your subscription

After you subscribe, choose Refresh in the SlideFidelity Account section to unlock Pro. Refunds are covered by the refund policy.

SlideFidelity Helper

SlideFidelity Helper is an optional, free app for PowerPoint on Mac and Windows computers. With it, SlideFidelity shows exactly which fonts are missing on this computer. Without it, SlideFidelity checks fonts against your show-machine font list. It is not available for PowerPoint on the web, iPad, or phones. Read what it installs, reads, and sends.

Install

Download the installer from the SlideFidelity Helper page, or choose Install when SlideFidelity offers it in the pane. The installer asks once for an administrator's approval. On Macs set up by Jamf or another MDM, you are asked once, when you first sign in, to approve the helper's certificate.

Uninstall

Mac: in Terminal, run sudo "/Library/Application Support/SlideFidelity/Helper/uninstall.sh". This removes the app, the login item, the certificate and its trust, and the helper's files.

Windows: open Settings › Apps › Installed apps, find SlideFidelity Helper, and select Uninstall.

Troubleshooting

If the SlideFidelity pane says Using show-machine list after you installed the helper, either the helper is not running or its certificate has not been approved yet.

  • Mac: approve the certificate prompt if you see one. If you dismissed it, sign out of your Mac and sign back in to see it again. Signing back in also starts the helper.
  • Windows: sign out and back in to start the helper, or reinstall it.
  • The helper's certificate lasts about two years. When SlideFidelity says it needs renewing, reinstall the helper.
  • When SlideFidelity says a helper update is available, download and run the new installer. Nothing installs automatically.

For IT and MDM

  • Silent install: deploy the pkg with Jamf or another Mac MDM, or the MSI with Intune. Neither needs a user prompt to install.
  • Mac certificate approval: each Mac needs one user approval of the helper's certificate, asked at the user's first sign-in after install. macOS does not allow changes to certificate trust without a user present.
  • Turn off update checks: on Mac, set the managed preference domain com.slidefidelity.helper, key AutoUpdate, to false. On Windows, set the registry value HKLM\Software\SlideFidelity\Helper AutoUpdate to 0. Then deploy new versions through your MDM.
  • Uninstall: run the Mac uninstall script above as root, or remove the MSI with Intune.

Contact support@slidefidelity.com for the Jamf and Intune deployment notes.

Why some items cannot be fixed

PowerPoint does not let add-ins change fonts and colors inside charts and SmartArt, fonts set only for Asian or complex scripts, or content on slide masters. SlideFidelity lists these so you can change them in PowerPoint.
