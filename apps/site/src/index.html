See every hidden problem in your PowerPoint decks

SlideCheck audits the open presentation and shows the problems PowerPoint hides: unwanted fonts, off-brand colors, oversized images, redundant slide masters, broken links, and hidden content. Every finding jumps to its slide and shape.

Get SlideCheck for PowerPoint

What it checks

  • Fonts: every font in the deck, including Asian and complex-script fonts, bullet fonts, and hidden list styles.
  • Colors: theme colors per master and every color set directly, grouped so you can see what is off-brand.
  • Images and file size: size per image and per slide, with images that are too big, too small, distorted, or cropped but still stored.
  • Slide masters: which layouts each slide uses, and which masters and layouts are unused.
  • Links: web links and linked files, including links to local drives that break on other computers.
  • File review: hidden slides and shapes, off-slide content, empty placeholders, speaker notes, comments, and document properties.

Inspect any shape

Select a shape and the Inspector shows its fonts by script, colors, links, image size and cropping, and any problems SlideCheck found on it.

Fix the common problems in place

SlideCheck Pro includes one-click fixes for fonts, colors, hidden and off-slide content, and links. Each fix shows a preview of what will change before it runs.

Some problems can only be reported. PowerPoint does not let add-ins change fonts and colors inside charts and SmartArt or content on slide masters, compress images, or remove unused masters. SlideCheck lists these so you can handle them in PowerPoint.
